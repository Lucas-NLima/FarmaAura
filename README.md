Descrição do projeto:
O objetivo foi criar um protótipo de uma farmácia virtual, contendo funcionalidades de registro, edição e exclusão de produtos, fornecedores e usuários.
O sistema possui uma página de login, uma página de registro, a página inicial, uma página de finalização de compra e uma página administrativa (admin), que permite a edição de produtos e o acompanhamento dos dados de vendas.
Cada produto também possui uma página dedicada com informações adicionais.
